# GUI and pipeline confidence gates

The 2026-10-22 expansion targets coverage of user actions and durable pipeline
transitions, not just a large docking count. This is local Mac validation; it
does not establish native Windows/Linux, consumer hardware or scientific
accuracy acceptance.

## Native interaction checklist

Every retained representative is exercised, not just the first image. Verify
exact pose/receptor links, independent PLIP legend types, master contact toggle,
protein cartoon, optional residue labels, per-residue visibility, unchanged
camera on visibility toggles, unchanged retained 2D image, absence of enabled
atom-selection markers, laptop/large window resizing, clean 2D/3D/paired PNG
exports, and close/restoration without saved-state or retained-evidence mutation.
One case also exercises optional CPU ray-traced export. Native screenshots and
custom exports require a separate visual review; receipt/file existence alone
cannot grant that gate.

`validation/build_gui_foundation_suite.py` prepares the ignored local suite.
`validation/contract_worker.py` enforces one executed, non-skipped contract per
receipt. `validation/retained_gui_worker.py` verifies every retained source hash,
uses an isolated study/settings copy and refuses unexpected dialogs. This is
not an adapter for granting new scientific approvals or repeating old searches.

## Release-blocking gaps remain visible

The foundation's score is not the release decision. Independently close the
five chronological raw-input paths and high-impact boundaries in
[the real workflow plan](gui-real-workflow-validation.md):

- Fresh public download and local PDB/mmCIF preparation through site review.
- Exact unique and repeated deposited-ligand selection, local chemistry checks,
  and real passing/failing strict controls without relaxed approval thresholds.
- Related-structure lookup on/off, unavailable connection, absent cavity and
  multi-region review without self-evidence or merged ligand-instance boxes.
- Real cancellation, resume/reopen and failure retention without duplicate jobs.
- All supported engines through their accepted chemistry paths; unsupported
  configurations must reject explicitly rather than being called successful docks.

User review is still required for changed prepared receptors/boxes, ambiguous
chemistry or unsupported interventions. Public example acquisition and fresh
pipeline work must be declared in the molecular panel; don't silently substitute
100 component assertions for 100 protein–ligand examples. Scientific accuracy
and pose recovery use independent criteria, not GUI pass counts.
