# Why Docking Universal is designed this way

Docking Universal began with a practical problem I encountered while using docking software: **how should I determine where to dock?** AutoDock Vina requires a search region, but that choice is scientifically consequential and is often treated as a setup detail. If no relevant ligand is available, candidate cavities must be detected, compared in structural context, and documented before a docking box is selected. If a relevant experimental ligand is available, I believe the workflow should also test whether the proposed protocol can recover evidence it already has.

I learned a great deal about how many consequential choices sit behind docking results while building this workflow. Protonation and tautomer states, molecular graphs, charge models, receptor preparation, retained components, pocket selection, box geometry, conformer generation, search effort, scoring, and clustering all introduce assumptions. Once those choices become a numerical score, structure, or polished figure, they can be easy to overlook.

**Computational assumptions are unavoidable; hidden assumptions are not.** Automation should reduce repetitive technical work without concealing how a result was produced or making scientifically consequential guesses on the user's behalf. Docking Universal therefore retains parameters, manifests, intermediate artifacts, raw tool logs, and the evidence used by its reports. When chemistry or structural ambiguity falls outside defined automation boundaries, it stops, explains the issue, and requests explicit user review. The user's selection, approval, or documented override—and the context that required it—becomes part of the audit trail.

The bound-ligand control reflects the same philosophy. Coordinates in a PDB file are not a complete, authoritative small-molecule representation: bond orders, aromaticity, formal charge, protonation, and stereochemistry may be absent or ambiguous. Docking Universal verifies the molecular graph using the RCSB Chemical Component Dictionary or a supplied SDF while keeping the crystallographic coordinates separate as a withheld evaluation reference. The control ligand then follows substantially the same preparation, conformer-generation, docking, scoring, and analysis path as an unknown compound.

A passing control is deliberately treated as target-specific retrospective evidence, not proof of prospective accuracy or affinity. A failed control prevents those settings from silently authorizing later screening. Ligand-free cavity rankings are likewise presented as reviewable hypotheses rather than biological conclusions.

The goal is a workflow that is practical to run without becoming a black box. It can carry a supported study from preparation through docking, analysis, visualization, and reporting, while leaving every stage available for investigation when a choice or result appears questionable.
