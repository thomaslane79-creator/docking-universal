# Docking Universal branding assets

The flat navy/teal mark is the approved Docking Universal identity. These are
original standalone assets copied from
`/Users/crown2/Documents/ChatGPT/docking_universal_logo_assets_high_res`; none
were cropped from a contact sheet.

Approved variants:

- `docking-universal-stacked.png`: primary stacked logo.
- `docking-universal-horizontal.png`: standard horizontal logo.
- `docking-universal-horizontal-compact.png`: compact horizontal logo.
- `docking-universal-icon-full-color.png`: full-color mark without text.
- `docking-universal-icon-dark.png`: simplified inverted mark for dark surfaces.
- `docking-universal-stacked-dark.png`: stacked reverse logo for dark surfaces.
- `docking-universal-horizontal-dark.png`: horizontal reverse logo for dark surfaces.
- `docking-universal-app-icon.png`: square full-color application icon.
- `docking-universal-favicon.ico`: multi-size favicon.

The GUI carries a runtime copy of the 512 px simplified full-color icon under
`libexec/docking_universal/gui/assets/branding`. Complex protein-render marks,
photorealistic molecular artwork, and grayscale variants are not approved GUI
or report branding and must not be substituted for these assets.
