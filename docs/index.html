Structural docking workflows · Ubuntu and macOS

Scientific docking workflow orchestration, validation, analysis, visualization, and reporting.

Docking Universal supports AutoDock Vina, QuickVina-W, and established open-source structural-bioinformatics tools. It provides guided workflows for complete studies, reusable protocol creation, and protocol-based screening while retaining composable commands, complete provenance, PyMOL Open-Source visualizations, and automatic scientific PDF reports.

The selected Vina-family engine performs the docking search and scoring. Docking Universal makes the surrounding established open-source toolchain reproducible, reviewable, batch-capable, and easier to run without launching each script manually.

Why I built it · a scientist's perspective

I had docking software. The first problem was: where should I dock?

Vina requires a search region, but choosing that region is scientifically consequential. Without a relevant ligand, I wanted candidate cavities to be detected, visualized, compared, and documented before selecting a box. With an experimental ligand, I wanted the workflow to test whether its proposed protocol could recover a known pose rather than simply assuming the setup was adequate.

SITE

Make site selection explicit

A known ligand defines an experimentally observed site; otherwise fpocket generates geometric cavity hypotheses for structural review.

CHEM

Coordinates are not complete chemistry

A PDB does not reliably encode an authoritative ligand molecular graph. CCD or supplied-SDF chemistry provides bonds, aromaticity, charge, and stereochemistry.

CTRL

Do not give the control an unfair advantage

The crystallographic conformation is withheld. The control ligand follows the same state, conformer, preparation, seed, Vina, scoring, and analysis pipeline used for unknown compounds.

SCOPE

Report what the evidence supports

A pass is target-specific pose-recovery evidence within a known site—not proof of prospective pose, affinity, or biological activity.

From scientific decisions to reusable reports and sessions

The guided Bash workflow records inputs, choices, parameters, seeds, versions, scores, and limitations. Both pathways continue through Vina docking and produce structured results, versioned PDF reports, PyMOL Open-Source sessions, and 2D interaction diagrams.

End-to-end package

From starting structures to interpretable output

  1. 01

    Prepare molecules

    Build receptor PDBQT files and optimized compound libraries with retained names and SMILES.

  2. 02

    Define sites

    Use a bound ligand or fpocket cavities to create explicit center and box coordinates.

  3. 03

    Calibrate + run

    Test known ligands across independent conformers and seeds, then lock successful settings for target-matched unknown docking.

  4. 04

    Visualize

    Generate PLIP scenes, headless PyMOL PNGs, and generic 2D molecular depictions.

Bound-ligand control

Verification is a visible Bash choice

The guided command lists exact RESNAME:CHAIN:RESNUM candidates with atom counts, asks for confirmation, and offers strict coordinate-free RCSB chemical-identity verification or a manual override with a required audit note.

2D

No pose leakage

Retains only the CCD molecular graph—bonds, charge, and stereochemistry—then embeds docking conformers independently. Neither CCD nor crystal coordinates seed the search.

RMSD

Pose-recovery evidence

Separately tests pose sampling, score ranking, and repeatability without fitting poses onto the crystal ligand.

JSON

Locked protocol

Records engine-specific settings, seeds, outcomes, and receptor/box hashes before unknown docking is allowed.

PSE

Separate review scenes

Writes crystal interactions, docked interactions, and crystal-versus-docked overlays.

Research preview

Scientifically useful, with validation still in progress.

Docking Universal packages transparent structural-docking computations. It does not prove biological relevance. The documented 1HVR/XK2 work includes a failed low-effort baseline and a successful multi-seed Vina ensemble follow-up. This target-specific control is reported as retrospective evidence rather than general accuracy validation.
