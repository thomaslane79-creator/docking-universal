# Docking Universal minimal GeoStd core

This history-free subset was selected from
[`phenix-project/geostd`](https://github.com/phenix-project/geostd) revision
`6b9ef76b4167e27c1530745e0311e8c5ac59338c`.

It contains the GeoStd list and energy files, RNA/DNA link/modification support,
and restraint CIFs for the twenty standard protein amino acids. It deliberately
does not claim to cover modified amino acids, cofactors, glycans, or arbitrary
ligands. Missing retained receptor components require an explicitly approved,
pinned component download or a complete offline library.

The upstream `LICENSE.txt` and `COPYRIGHT.txt` are retained in this directory.
